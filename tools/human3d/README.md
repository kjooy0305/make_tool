# 인간 3D 모델 스튜디오

브라우저에서 사람 3D 모델을 만들고 자세와 구도를 잡는 도구.

## 만드는 방식
1. **뼈대**: 사람 뼈대 52개(척추·머리·팔·손가락 15개·다리·발가락). 기준 위치는 Blender 5.2 Rigify 사람 메타리그(GPL-2.0-or-later)에서 읽은 숫자(`ref.js`)이고, 길이 계수로 늘이고 줄인다.
2. **모양**: 뼈마다 타원 캡슐·타원체(몸통 단면, 팔다리, 손바닥, 손가락, 머리, 턱, 코, 입술, 귀…)를 두고 거리장(SDF)으로 부드럽게 이어 붙인다. 살집·근육·성별 값은 단면 크기에 곱한다.
3. **표면**: Surface Nets 로 하나로 이어진 메시를 뽑고 Taubin 평활화, 법선, 입술색·어두운 곳 색(정점 색)을 계산한다.
4. **스킨**: 가까운 모양의 뼈일수록 크게 가중치를 줘서 상위 4개 뼈에 묶는다. 같은 가중치로 머리카락과 옷(몸을 부풀린 껍질)도 묶는다.
5. **자세**: 뼈 회전(X/Y/Z, 좌우 대칭, 손가락 마디별), 완성 포즈 20개, 손 모양 6개.

## 파일
- `ref.js` 기준 비율(숫자만), `body.js` 생성기(DOM 없이 Node 에서도 돈다), `app.js` 화면·3D·내보내기, `index.html`.

## 내보내기
GLB(뼈대·스킨 포함, 기본 자세), OBJ(현재 자세), PNG(투명 배경 옵션, 구도 틀 안쪽만), 프로젝트 JSON.

## 한계와 다음 단계
- 조각 브러시(자유 변형)는 아직 없다. 체형은 슬라이더 조합으로 만든다.
- 얼굴은 눈·코·입술·턱·귀 위주의 단순한 형태다. 표정과 얼굴 뼈는 없다.
- 옷은 몸을 부풀린 껍질이라 헐렁한 옷·치마는 아직 없다.
